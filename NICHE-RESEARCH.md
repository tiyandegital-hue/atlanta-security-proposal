# Niche research — security agency websites (2026-10-25)

Rule applied: niche research FIRST, before designing (Tanjir's order 2026-10-25).
Lead driving this build: Yashh (@batman.null, Threads, 2026-10-25) — website
developer + SEO for a security agency in Atlanta, budget $2,000.
Sources: Medium (security lead-gen features), FireArt inspirational list, Webflow
security templates, Instapage guard-company landing guide, Qrolic 2025 guide,
Zegashop guard/patrol service-site guides + 1 real site opened and read directly:
Access Control Security (accesscontrolsecurity.com, Los Angeles guard firm).

## Patterns found across the best security sites

1. **Dedicated page per service (SEO + clarity).** Guard services, CCTV, event,
   corporate, residential, alarm monitoring each get their own page: what it
   includes, who it is for, benefits. This is also exactly what Yashh asked
   for (website + SEO) — so the build uses dynamic service pages, not one list.
2. **Trust above the fold, in 3 seconds.** Security buyers decide on trust:
   clear value prop + visible next step immediately. No clever slow reveals.
3. **Strong CTAs on every page.** "Get a Free Quote", "Request Security
   Consultation", "Book a Security Assessment" — repeated, never buried.
4. **Short lead form, only essentials.** Name, email, phone, message. Long forms
   kill conversion. Clear next step after submit.
5. **Trust signals — but ONLY real ones here.** The niche uses reviews, certs,
   years-in-business, case studies, team bios. For this proposal sample NONE of
   those are invented: no fake reviews, stats, licences, staff, or clients.
   Trust is carried by: transparent services, clear process (Assess → Deploy →
   Report), service areas, FAQ, and a real quote path.
6. **Dark conventional palette.** Physical security = dark colors (black/navy,
   often red or gold accent). Premium + serious, never playful.
7. **Local SEO structure.** Location pages, Atlanta keywords in titles, internal
   links between services/areas/FAQ, semantic HTML, fast mobile pages.
8. **Contact always visible.** Phone/email in header on real sites. Here the
   agency is unnamed, so the real contact path is the quote form → email to
   Tiyan Digital (the proposal sender), never an invented phone/address.

## Deliberately NOT adopted

- Reviews/testimonials, certifications, years, client logos — unverified, would
  be invented. Skipped.
- "Licensed & insured" badge claims, response-time numbers — unverified. Skipped.
- Live-chat / booking-calendar widgets — fake functionality. Skipped.
- Any "demo / concept / not affiliated" banner — removed per Tanjir's direct
  order 2026-10-25 for this proposal build. The site is presented to the lead
  as a proposal sample in Tanjir's own message; the agency name is a
  placeholder (real agency unnamed in the lead post) and must be confirmed
  before anyone presents it as the agency's live site.

## Build direction (from this research)

Dark navy + amber premium theme. Photo-led hero (licensed Commons photos only),
value prop + Get-Free-Quote CTA above the fold, service pages for SEO, Atlanta
areas page, FAQ, short quote form with a REAL action (mailto to Tiyan Digital),
Privacy/Terms that truthfully describe the form. Fast, light JS — speed is part
of the SEO pitch.
